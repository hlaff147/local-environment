# 🚀 Cheat Sheet Básico — macOS Environment

> Guia rápido e direto ao ponto com os **comandos essenciais** que você vai usar todo dia. Para a versão completa, consulte o `KEYBINDINGS.md`.

---

## 🪟 AeroSpace (Navegação de Janelas)
O AeroSpace organiza suas janelas. O botão mestre é o **`Alt (⌥)`**.

| Ação | Atalho |
|---|---|
| Mover foco entre janelas | `⌥ H` (esq), `⌥ J` (baixo), `⌥ K` (cima), `⌥ L` (dir) |
| Alternar entre Workspaces | `⌥ 1` até `⌥ 9` |
| Voltar ao Workspace anterior | `⌥ .` (ponto) |
| Tela Cheia (Fullscreen) | `⌥ F` |

---

## 🎩 Alfred (Busca e Apps)
Substitui o Spotlight padrão.

| Ação | Atalho |
|---|---|
| Abrir Alfred | `⌘ Espaço` |
| Abrir aplicativo | `[nome do app]` |
| Rodar comando no terminal | `> [comando]` |

---

## 👻 Ghostty (Terminal)
Seu terminal rápido e limpo.

| Ação | Atalho |
|---|---|
| Nova Aba | `⌘ T` |
| Fechar Aba | `⌘ W` |
| Mudar de Aba | `⌘ ⇧ [` ou `⌘ ⇧ ]` |
| Dividir a tela (Split) | `⌘ D` (lado a lado) ou `⌘ ⇧ D` (em cima/baixo) |

---

## 🐚 Terminal Zsh & Ferramentas
Atalhos que funcionam direto no terminal.

| Ação | Comando/Atalho |
|---|---|
| Abrir o NeoVim | `v` ou `vi` |
| Navegação inteligente de pastas | `z [nome da pasta]` |
| Buscar arquivo no diretório | `Ctrl + T` |
| Buscar comando no histórico | `Ctrl + R` |
| Subir/Derrubar Docker | `dcup` (subir) / `dcdown` (derrubar) |

---

## ✏️ NeoVim (LazyVim + VSCode Keymaps)
Seu editor principal. A tecla líder (**Leader**) é o **`Espaço`**.

### Edição Básica (Estilo VSCode 🔵)
| Ação | Atalho |
|---|---|
| Salvar Arquivo | `⌘ S` |
| Desfazer / Refazer | `⌘ Z` / `⌘ ⇧ Z` |
| Fechar Aba/Buffer | `⌘ W` |
| Multi-Cursor | Selecione e aperte `Ctrl + D` |

### Navegação de Arquivos e Busca
| Ação | Atalho |
|---|---|
| Abrir explorador de arquivos | `⌘ B` |
| Buscar arquivo (Quick Open) | `⌘ P` ou `Space Space` |
| Buscar texto no projeto (Grep) | `⌘ ⇧ F` |
| Buscar comando (Command Palette) | `⌘ ⇧ P` |

### Inteligência de Código
| Ação | Atalho |
|---|---|
| Ir para Definição | `F12` |
| Ações rápidas (Quick Fix) | `⌘ .` |
| Formatar documento | `⌘ ⇧ I` |
| Comentar linha | `⌘ /` |
| Autocomplete Inteligente | Comece a digitar (Copilot entra automático) |

### Git (LazyGit)
| Ação | Atalho |
|---|---|
| Abrir interface do Git | `Space g g` |
